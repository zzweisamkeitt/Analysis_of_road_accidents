# Analysis_of_road_accidents
Данное исследование освящает причины тяжести ДТП в Республике Тыве - антилидеру по уровню смертности. Данные были взяты с сайта официальной статистики ГИБДД (http://stat.gibdd.ru/) в виде карточек подробно описывающих случаи ДТП.

# Прогнозирование фатальности ДТП в Республике Тыва

Исследование факторов тяжести дорожно-транспортных происшествий с применением методов машинного обучения.

## О проекте

Анализ детализированных карточек ДТП в Республике Тыва (2021–2026 гг.) — регионе с наихудшим показателем смертности на дорогах в России (32,7 на 100 тыс. жителей). Цель — сравнить классические эконометрические модели и ансамблевые ML-алгоритмы в задаче бинарной классификации фатального исхода аварии.

## Данные

- **Источник:** ГИБДД (stat.gibdd.ru)
- **Период:** январь 2021 — январь 2026
- **Структура:** две связанные таблицы — карточки ДТП и участники (join по ID происшествия)
- **Целевая переменная:** `fatal` — бинарный индикатор наличия погибших (~15% положительного класса)
- **Разбивка:** Train (01.2021–02.2025) / Validation (03.2025–08.2025) / Test (09.2025–01.2026) — по времени, без утечки из будущего

## Ключевые находки

**Факторы риска (устойчивые по всем моделям):**
- Тип ДТП: наезд на велосипедиста (+3x к шансам фатального исхода), наезд на пешехода (+2.2x), съезд с дороги (+1.9x)
- Значение дороги: региональные/федеральные трассы vs. местные дороги
- Освещение: тёмное время суток без освещения
- Наличие грузового транспорта (+40% к шансам)

**Нелинейные эффекты (GAM, CatBoost, RF):**
- Время суток: U-образная зависимость — риск выше ночью и ранним утром
- Сезонность: рост вероятности фатального исхода к осени (сентябрь–ноябрь)
- День недели: выходные опаснее будних
- Число участников: нелинейный рост риска, наиболее опасны аварии с двумя ТС

**STRICT vs EXTENDED:** расширение набора признаков не улучшает качество и добавляет шум — компактная спецификация предпочтительнее.
